# Мастерок 3.0

Проект расширяет исходную версию, сохраняя шесть исходных калькуляторов и их формулы.

## Что реализовано
- Проекты: создание, переименование, удаление (последний проект защищён от удаления), переключение.
- Изоляция данных проектов: сметы, сохранённые расчёты, история и отдельные значения полей калькуляторов.
- Смета: пользовательское название работы, единица, количество, цена за единицу, автоматический итог, редактирование и удаление.
- Калькуляторы: помещение, плитка, штукатурка/шпаклёвка, краска, обои, стяжка; сохранение результата в активный проект.
- Хранение: IndexedDB с резервным зеркалом LocalStorage; импорт/экспорт резервной копии JSON.
- Миграция ранее сохранённых полей из ключа `masterok-v2`.
- PWA/offline cache и конфигурация Capacitor.

## Запуск веб-версии
Откройте `index.html` через локальный сервер или разместите папку на HTTPS-хостинге. Для обычного локального теста можно использовать:
`python -m http.server 8000`

## Android APK
См. `ANDROID_BUILD_RU.md`. Требуются Node.js, JDK 17 и Android Studio/SDK. Для сборки без Android Studio добавлен GitHub Actions workflow `.github/workflows/build-android.yml`. Инструкции — в `ANDROID_BUILD_RU.md`.
