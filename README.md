# Мастерок 3.2

Проект расширяет исходную версию, сохраняя шесть исходных калькуляторов и их формулы.

## Что реализовано
- Проекты: создание, переименование, удаление (последний проект защищён от удаления), переключение.
- Изоляция данных проектов: сметы, сохранённые расчёты, история и отдельные значения полей калькуляторов.
- Смета: пользовательское название работы, единица, количество, цена за единицу, автоматический итог, редактирование и удаление.
- Коммерческие предложения (вкладка «КП»): создание из проекта (название, работы, количества и цены копируются из сметы) или с нуля; редактирование, копирование, удаление; необязательные поля (клиент, исполнитель, телефон, адрес, описание, сроки, условия оплаты); работы и материалы с автоматическим расчётом итогов. Предложение — независимая копия: его правки не меняют проект и смету. Хранится в том же `state` (ключ `proposals`), поэтому попадает в IndexedDB и в экспорт/импорт резервной копии.
- Экспорт КП в PDF (кнопка «Экспорт в PDF» в карточке предложения): A4, многостраничная вёрстка, стиль Dark Premium. Подробности — ниже.
- Калькуляторы: помещение, плитка, штукатурка/шпаклёвка, краска, обои, стяжка; сохранение результата в активный проект.
- Хранение: IndexedDB с резервным зеркалом LocalStorage; импорт/экспорт резервной копии JSON.
- Миграция ранее сохранённых полей из ключа `masterok-v2`.
- PWA/offline cache и конфигурация Capacitor.

## Запуск веб-версии
Откройте `index.html` через локальный сервер или разместите папку на HTTPS-хостинге. Для обычного локального теста можно использовать:
`python -m http.server 8000`

## Android APK
См. `ANDROID_BUILD_RU.md`. Требуются Node.js, JDK 17 и Android Studio/SDK. Для сборки без Android Studio добавлен GitHub Actions workflow `.github/workflows/build-android.yml`. Инструкции — в `ANDROID_BUILD_RU.md`.

## Экспорт КП в PDF
- Кнопка «Экспорт в PDF» находится вверху открытого предложения. Документ собирается из копий данных предложения; суммы берутся из тех же функций, что и на экране (`lineSum`, `propTotals`), данные не меняются.
- Генератор — `pdf-kp.js` (без внешних зависимостей, работает офлайн и в Android WebView), шрифты — `pdf-fonts.js` (подмножества Inter и Lora, лицензия SIL OFL 1.1; кириллица и «₽» встроены в PDF). Оба файла добавлены в кэш `sw.js` и в `scripts/copy-web.js`.
- Пустые поля в документ не попадают: нет клиента — нет блока клиента, нет материалов — нет таблицы материалов и т. д. Предложение без позиций не экспортируется.
- Файл называется `KP_<название-латиницей>_<дата>.pdf` (кириллица в имени скачиваемого файла теряется в части браузеров).
- Пересборка шрифтов: `python tools/build-pdf-fonts.py --inter <папка с Inter OTF> --lora <Lora-Variable.ttf>` (нужен `pip install fonttools`).
- Android (APK): в WebView скачивание по ссылке `blob:` может не работать. Для надёжной отправки/сохранения добавьте плагины `@capacitor/filesystem` и `@capacitor/share` и выполните `npm run android:sync` — код в `deliverPdf()` использует их автоматически, если они есть.
